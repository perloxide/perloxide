# Windows where Perl has no defined behavior

Facts only: what `perl` does, demonstrated by a probe.  What an implementation chooses to do in these windows is that
implementation's decision and is documented with it.

| Window                                                                                                                                                                                                               | Perl's behavior                                                                                                                                                                                        | Demonstrated by                                                                        |
|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------|
| W1: a `__WARN__` handler replaces the string being numified with a number, and the outer op is an NV conversion (`sprintf "%g"`, `%.17g`)                                                                            | `SIGSEGV`: `sv_2nv_flags` calls `Atof` on the freed PV after the handler                                                                                                                               | `suites/reentry` (114 crash cells)                                                     |
| W2: the handler replaces it with a reference, same outer op                                                                                                                                                          | reads the RV pointer through the `svu` union; observed stable as `n=0`, layout-dependent                                                                                                               | `suites/reentry` (51 cells)                                                            |
| W3: a reference holder with an infinite NV reaching `sv_2iuv_non_preserve` in the IV window                                                                                                                          | crash on a scalar-ref replacement, survives an array-ref replacement; trigger not root-caused                                                                                                          | `suites/reentry`                                                                       |
| an `undef` replacement under `sprintf "%g"`                                                                                                                                                                          | infinite `__WARN__` loop (timeout) on one machine, `SIGSEGV` on another                                                                                                                                | `suites/reentry`                                                                       |
| `shift @_` while two aliases into `@_` are held                                                                                                                                                                      | `SIGSEGV` (`@_` storage is not refcounted)                                                                                                                                                             | `suites/aliasing` A12                                                                  |
| `delete` during `values` aliasing                                                                                                                                                                                    | order- and memory-dependent                                                                                                                                                                            | `suites/aliasing` A26                                                                  |
| cross-statement `refaddr` equality of tied-container element mirrors                                                                                                                                                 | reuse of a freed mirror's memory; a held reference always yields a distinct address                                                                                                                    | `models/SS` (masked in both columns)                                                   |
| `local` on a `threads::shared` scalar                                                                                                                                                                                | the localized value is visible to other threads                                                                                                                                                        | `probes/research/value-flags/p4.pl`                                                    |
| within-pass order of `DESTROY` in global destruction                                                                                                                                                                 | arena order, a property of allocation history                                                                                                                                                          | `models/FZ` (compared as sets)                                                         |
| any upgrade of a weak reference to the dying object inside a tied holder's `STORE(undef)` while `sv_kill_backrefs` clears the holders, kept, transient, reweakened, or reblessed; or undefining a later holder there | the body is freed anyway, nothing rechecks the count: `SIGSEGV`/`SIGABRT`, a second `DESTROY`, or a silently leaked freed SV, by form and build; `undef` of a later holder croaks `panic: del_backref` | `probes/research/value-model/25_kill_backrefs_reentry.pl` (every `MODE` but `observe`) |
