# Windows where Perl has no defined behavior

Facts only: what `perl` does, demonstrated by a probe.  What an implementation chooses to do in these windows is that
implementation's decision and is documented with it.  A window that a bug in perl opens names the bug, which
`perl-bugs.md` describes; the third window of `warn-handler-continuation`, W3, has a defined outcome (a deterministic
panic) and is described there only.
